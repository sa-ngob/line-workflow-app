# ESPA Engineering — LINE Flex Message Templates

ชุดการ์ดแจ้งเตือนภายในองค์กร สำหรับโรงงานฉีดพลาสติกและผลิตแม่พิมพ์ แยก 1 แผนกต่อ 1 ไฟล์

> ไฟล์ในโฟลเดอร์นี้สร้างจาก `scripts/build-espa-templates.ts`
> ถ้าจะแก้โครงการ์ดหรือสีให้แก้ที่สคริปต์แล้วรันใหม่ จะได้ครบทั้ง 8 แผนกพร้อมกัน
> แก้ไฟล์ `.json` ตรง ๆ ก็ได้ แต่การรันสคริปต์ครั้งถัดไปจะเขียนทับ

```bash
npx tsx scripts/build-espa-templates.ts    # สร้างใหม่ทั้งชุด
npx tsx scripts/check-espa-templates.ts    # ตรวจก่อนใช้จริง
```

| ไฟล์ | แผนก | Placeholder | สีหลัก |

| `hr.json` | ฝ่ายทรัพยากรบุคคล | `{{HR_*}}` | #0F766E |
| `admin.json` | ฝ่ายธุรการ | `{{ADMIN_*}}` | #475569 |
| `account.json` | ฝ่ายบัญชีและการเงิน | `{{ACCOUNT_*}}` | #B45309 |
| `production.json` | ฝ่ายผลิต | `{{PRODUCTION_*}}` | #1D4ED8 |
| `technical.json` | ฝ่ายเทคนิคและซ่อมบำรุง | `{{TECHNICAL_*}}` | #C2410C |
| `mold.json` | ฝ่ายแม่พิมพ์ | `{{MOLD_*}}` | #6D28D9 |
| `sale.json` | ฝ่ายขาย | `{{SALE_*}}` | #15803D |
| `management.json` | ฝ่ายบริหาร | `{{MANAGEMENT_*}}` | #0F172A |

## รูปแบบไฟล์

ทุกไฟล์เป็น LINE Messaging API message object พร้อมใช้ในรายการ `messages`:

```json
{
  "type": "flex",
  "altText": "ข้อความสำรอง",
  "contents": { "type": "bubble" }
}
```

## ช่องที่กรอกได้ (เหมือนกันทุกแผนก ต่างกันที่ป้ายบนการ์ด)

| ส่วนท้าย | ความหมาย | ตัวอย่าง |
|---|---|---|
| `_ALT_TEXT` | ข้อความสำรองในรายการแชต | `แจ้งผลทดลองฉีด M-2026-014` |
| `_HERO_IMAGE_URL` | รูปหัวการ์ด (HTTPS, อัตราส่วน 20:9) | `https://example.com/mold.jpg` |
| `_TITLE` | หัวข้อหลัก | `ผลทดลองฉีด T1 ผ่านเกณฑ์` |
| `_MESSAGE` | รายละเอียด | `ชิ้นงานได้ขนาดตามแบบ รอตรวจผิวงาน` |
| `_REFERENCE_NO` | เลขอ้างอิง (ป้ายต่างกันตามแผนก) | `M-2026-014` |
| `_STATUS` | สถานะ | `ผ่าน T1` |
| `_DATETIME` | วันที่และเวลา | `16 ส.ค. 2026 09:30` |
| `_OWNER` | ผู้รับผิดชอบ | `คุณสมชาย` |
| `_NOTE` | หมายเหตุสั้น | `รอผลตรวจ CMM ก่อนส่งมอบ` |
| `_PRIMARY_URL` | ลิงก์ปุ่มหลักและรูป | `https://intranet.example.com/mold/14` |
| `_SECONDARY_URL` | ลิงก์ปุ่มรอง | `https://intranet.example.com/contact` |

**ช่องที่ไม่กรอกจะหายไปจากการ์ดเอง** ไม่ต้องกรอกครบทุกช่อง — แถวที่ไม่มีค่าจะถูกตัดทั้งแถว
ไม่เหลือป้ายลอย, ไม่ใส่รูปก็ไม่มีหัวการ์ดรูป, ไม่ใส่ลิงก์ปุ่มนั้นก็หายไป
(ตรรกะอยู่ใน `src/services/espaTemplates.ts`)

## เรื่องที่แต่ละแผนกใช้ส่ง

### ฝ่ายทรัพยากรบุคคล (`hr`)

| ช่อง | ป้ายบนการ์ด |
|---|---|
| `REFERENCE_NO` | เลขที่ประกาศ |
| `STATUS` | สถานะ |
| `DATETIME` | มีผลวันที่ |
| `OWNER` | ผู้ประกาศ |

งานที่เลือกได้จาก dropdown:

- **ประกาศตารางกะและโอที** — ประกาศตารางกะประจำสัปดาห์
- **นัดอบรมความปลอดภัย** — อบรมความปลอดภัยประจำเดือน
- **ประกาศรับสมัครงาน** — เปิดรับสมัครช่างประจำโรงงาน
- **แจ้งผลอนุมัติการลา** — แจ้งผลอนุมัติการลา

### ฝ่ายธุรการ (`admin`)

| ช่อง | ป้ายบนการ์ด |
|---|---|
| `REFERENCE_NO` | เลขที่เรื่อง |
| `STATUS` | สถานะ |
| `DATETIME` | กำหนดส่ง |
| `OWNER` | ผู้ดูแลเรื่อง |

งานที่เลือกได้จาก dropdown:

- **แจ้งเวียนเอกสาร/ระเบียบ** — แจ้งเวียนระเบียบปฏิบัติฉบับใหม่
- **แจ้งกำหนดรถรับส่ง** — ปรับกำหนดการรถรับส่งพนักงาน
- **ติดตามใบขอซื้อ** — อัปเดตสถานะใบขอซื้อวัสดุ
- **แจ้งซ่อมอาคาร** — แจ้งงานซ่อมบำรุงอาคาร

### ฝ่ายบัญชีและการเงิน (`account`)

| ช่อง | ป้ายบนการ์ด |
|---|---|
| `REFERENCE_NO` | เลขที่เอกสาร |
| `STATUS` | สถานะชำระ |
| `DATETIME` | ครบกำหนด |
| `OWNER` | ผู้ติดต่อ |

งานที่เลือกได้จาก dropdown:

- **แจ้งวางบิล/ใบแจ้งหนี้** — แจ้งวางบิลงวดปัจจุบัน
- **เตือนครบกำหนดชำระ** — แจ้งเตือนลูกหนี้ครบกำหนดชำระ
- **แจ้งรับชำระเงินแล้ว** — ได้รับชำระเงินเรียบร้อย
- **ขอเอกสารประกอบภาษี** — ขอเอกสารประกอบการยื่นภาษี

### ฝ่ายผลิต (`production`)

| ช่อง | ป้ายบนการ์ด |
|---|---|
| `REFERENCE_NO` | Job No. / งานฉีด |
| `STATUS` | สถานะไลน์ผลิต |
| `DATETIME` | กะ / ช่วงเวลา |
| `OWNER` | หัวหน้ากะ |

งานที่เลือกได้จาก dropdown:

- **แจ้งเริ่มงานฉีด/เปลี่ยนรุ่น** — เริ่มงานฉีดรุ่นใหม่
- **รายงานยอดผลิตรายกะ** — สรุปยอดผลิตประจำกะ
- **แจ้งไลน์หยุด** — แจ้งไลน์ผลิตหยุดชั่วคราว
- **แจ้งเปลี่ยนแม่พิมพ์** — เปลี่ยนแม่พิมพ์บนเครื่องฉีด

### ฝ่ายเทคนิคและซ่อมบำรุง (`technical`)

| ช่อง | ป้ายบนการ์ด |
|---|---|
| `REFERENCE_NO` | เลขที่ใบแจ้งซ่อม |
| `STATUS` | สถานะงานซ่อม |
| `DATETIME` | นัดเข้าดำเนินการ |
| `OWNER` | ช่างผู้รับผิดชอบ |

งานที่เลือกได้จาก dropdown:

- **แจ้งเครื่องฉีดขัดข้อง** — เครื่องฉีดขัดข้อง อยู่ระหว่างแก้ไข
- **แจ้งกำหนด PM เครื่องจักร** — แจ้งกำหนดบำรุงรักษาเชิงป้องกัน
- **แจ้งซ่อมไฮดรอลิก/ฮีตเตอร์** — งานซ่อมระบบไฮดรอลิกและฮีตเตอร์
- **ติดตามอะไหล่** — รออะไหล่เข้าเพื่อดำเนินการต่อ

### ฝ่ายแม่พิมพ์ (`mold`)

| ช่อง | ป้ายบนการ์ด |
|---|---|
| `REFERENCE_NO` | รหัสแม่พิมพ์ |
| `STATUS` | สถานะงานแม่พิมพ์ |
| `DATETIME` | กำหนดทดลองฉีด |
| `OWNER` | ผู้ควบคุมงาน |

งานที่เลือกได้จาก dropdown:

- **ความคืบหน้างานสร้างแม่พิมพ์** — อัปเดตความคืบหน้างานสร้างแม่พิมพ์
- **นัดทดลองฉีด T0/T1** — นัดทดลองฉีดแม่พิมพ์
- **แจ้งผลทดลองฉีด** — ผลทดลองฉีดผ่านเกณฑ์
- **แจ้งซ่อม/ขัดเงาแม่พิมพ์** — งานซ่อมและขัดเงาแม่พิมพ์
- **แจ้งส่งมอบแม่พิมพ์** — ส่งมอบแม่พิมพ์ให้ฝ่ายผลิต

### ฝ่ายขาย (`sale`)

| ช่อง | ป้ายบนการ์ด |
|---|---|
| `REFERENCE_NO` | เลขที่ใบสั่งซื้อ |
| `STATUS` | สถานะออเดอร์ |
| `DATETIME` | กำหนดส่งมอบ |
| `OWNER` | ผู้ดูแลลูกค้า |

งานที่เลือกได้จาก dropdown:

- **แจ้งใบเสนอราคา** — ส่งใบเสนอราคาให้ลูกค้าแล้ว
- **แจ้งรับ PO ใหม่** — รับใบสั่งซื้อจากลูกค้า
- **อัปเดตสถานะออเดอร์** — อัปเดตความคืบหน้าออเดอร์
- **แจ้งเลื่อนกำหนดส่ง** — แจ้งเลื่อนกำหนดส่งมอบ

### ฝ่ายบริหาร (`management`)

| ช่อง | ป้ายบนการ์ด |
|---|---|
| `REFERENCE_NO` | เลขที่รายงาน |
| `STATUS` | สถานะ |
| `DATETIME` | รอบรายงาน |
| `OWNER` | ผู้จัดทำ |

งานที่เลือกได้จาก dropdown:

- **สรุปผลประกอบการรายวัน** — สรุปยอดผลิตและยอดขายประจำวัน
- **รายงาน OEE และของเสีย** — รายงานประสิทธิภาพเครื่องจักรและของเสีย
- **แจ้งนโยบาย/มติที่ประชุม** — แจ้งมติที่ประชุมและนโยบาย
- **แจ้งรายการผิดปกติ** — พบรายการผิดปกติที่ต้องพิจารณา

## ข้อควรระวัง

- ข้อความปุ่มยาวได้ไม่เกิน 20 ตัวอักษร และสีต้องเป็น hex 6 หลัก — `check-espa-templates.ts` ตรวจให้แล้ว
- `altText` ควรสื่อความหมายได้ด้วยตัวเอง และไม่ควรมีข้อมูลอ่อนไหว
- URL รูปต้องเป็น HTTPS และเปิดได้จากอินเทอร์เน็ต ไม่ใช่ IP ภายในโรงงาน
- หลีกเลี่ยงเงินเดือน เลขบัญชี หรือข้อมูลส่วนบุคคลบนการ์ด เพราะเห็นได้ทุกคนในกลุ่ม
- ตรวจกลุ่มปลายทางก่อนส่งทุกครั้ง การ์ดของฝ่ายบัญชีไม่ควรหลุดเข้ากลุ่มหน้างาน
